# Personal Library Management

Aplikasi untuk mengelola koleksi buku pribadi dengan dukungan banyak akun.

## Technology Stack

- Frontend: Next.js
- Backend: NestJS
- Database: PostgreSQL
- ORM: Prisma
- Authentication: JWT

## Project Structure

- `frontend/`: aplikasi frontend
- `backend/`: REST API
- `docs/`: dokumentasi proyek

## Team

- Frontend Developer
